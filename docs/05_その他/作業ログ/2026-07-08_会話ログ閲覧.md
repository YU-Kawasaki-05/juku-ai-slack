# 2026-07-08 会話ログ閲覧（SCR-13 / FR-19）

## 概要

管理画面から生徒×Bot のスレッド会話を閲覧できる会話ログ機能（P1）を実装。
スタッフのサポート・回答品質確認に使う閲覧専用機能。

## 実装内容

- `src/features/conversation-logs/lib/getConversations.ts`
  - `getThreads`: slack_thread_sessions 一覧（生徒名結合 + チャンネル名解決 + メッセージ件数）。
    フィルタは生徒・期間（全期間/7/30/90日）
  - `getThreadDetail`: スレッド + メッセージ時系列。person_id + channel_id + thread_ts で
    厳密に絞り別生徒の混入を防止（BR-05-11）
  - 純関数 `countMessagesByThread` / `formatMessageTime` を分離しテスト（4件）
- `src/features/conversation-logs/components/ConversationsFilter.tsx`（生徒・期間、URL 同期）
- `src/app/admin/conversations/{page,[id]/page}.tsx`
  - 一覧: テーブル（生徒/チャンネル/概要/件数/最終メッセージ）+ 空状態
  - 詳細: チャット形式（生徒=右/primary、Bot=左/muted、アバター・時刻・画像添付バッジ）+
    スレッド要約カード
- サイドバー「会話ログ」追加・パンくず対応
