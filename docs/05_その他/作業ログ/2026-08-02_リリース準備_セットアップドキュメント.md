### 調査結果1: セットアップ要件（逆引き調査、完了）

顧客先セットアップに必要な全要素が確定。主な発見:

**確定した構成**
- 接続方式: HTTP Events API（Socket Mode 不使用）。Request URL = `/api/slack/events`
- 必要 Slack scopes: `chat:write`, `reactions:write`, `channels:history`（非公開なら `groups:history`）, `files:read`。設計doc記載の `channels:read`/`users:read` は実は不要
- 購読イベント: `message.channels`（`app_mention` は購読不要 — メンション検出は message 本文の文字列一致）
- Bot を各生徒チャンネルに `/invite` する必要あり
- デプロイ: Vercel 前提（`after()` 使用）。Pro プラン事実上必須

**発見された問題（修正候補）**
1. `kill_switch` / `ENABLE_AI` 未実装 — コスト暴走時にアプリ内から AI を止められない（DEC-15 未達）。運用上最大のリスク
2. `RESEND_*` が未使用なのに env スキーマ上必須 — 未設定だと Slack 連携ごと 500。ダミー値強制は罠
3. `maxDuration` 未設定 — Vercel 既定タイムアウトで AI 処理が完走しない恐れ
4. `MODEL_PRICING` がハードコード5モデルのみ — OpenRouter 形式のモデル名だとコスト 0 円表示
5. ダッシュボードコスト集計が 1000 行で頭打ち（黙って過少表示）
6. `docs/03_技術設計/03_外部サービス.md` が実装と大幅ドリフト（waitUntil/ANTHROPIC_API_KEY/Sentry/Cron 等）
7. CI の env リストが古い（`ANTHROPIC_API_KEY` を渡し `LLM_*` を渡していない）
8. 未使用依存: `@anthropic-ai/sdk`, `ai`, `resend`, `@tanstack/react-query`
9. RLS は全 authenticated に `USING(true)` — Auth サインアップ無効化が実質の境界（手順書に明記必要）
10. 型生成スクリプトが `--local` 固定
