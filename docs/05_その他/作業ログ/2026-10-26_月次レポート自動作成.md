# 2026-10-26 月次レポートの自動作成とメール送付

FR-08 の未実装部分（AC-08-01 の AI 月次自動作成）を、Slack 版に実装した。Web 版（marubo_ai）の
`monthlyReport.ts`（chunk 分割・再開・Cron 認証・Resend の fetch）を参考に、Slack 版のテーブルと LLM クライアントへ書き直した。

## 実装したこと

- cron: `vercel.json`（毎月 1〜3 日 0:00 UTC）→ `GET /api/cron/monthly-reports`（Bearer `CRON_SECRET`）
- 作成: `src/features/monthly-reports/`（前月の判定は日本時間。再開・手書きを上書きしない・人数と時間の上限）
- メール: Resend の HTTP API を `fetch`。二重送信防止は `monthly_report_runs`（migration 033）+ 送信権の取得 + Idempotency-Key
- 管理画面: 「先月分を今すぐ作成して送る」（admin のみ）、レポート詳細に「Markdown で保存」
- 文書: FR-08・スタッフマニュアル（第 4・6・7 章ほか）・セットアップ（step5・04_セットアップ手順・03_外部サービス）
