# 2026-08-30 バックアップ保存先の決定（private GitHub リポジトリ）

`2026-08-27_バックアップとリストア手順.md` の続き。あちらで「保存先は未決定」としていた点を確定させた。

## 決めたこと

**保存先 = バックアップ専用の private GitHub リポジトリ**（Actions artifact 90 日 + 月初は Releases）。

保存先候補の変遷と、それぞれを落とした理由:

| 案 | 結果 | 理由 |
|---|---|---|
| 公開リポジトリの Actions artifact | 却下 | public の artifact は**認証なしで誰でも DL できる**。未成年の PII を置けない |
| Cloudflare R2 | 却下 | 有効化に支払い方法の登録が必要で、**デビットカードでは通らなかった** |
| **private リポジトリ** | **採用** | GitHub Free はカード登録不要 / private 無制限 / Actions 2,000分・artifact 500MB 無料 |

## セキュリティ設計の変更（今回の主眼）

前版の §6 は「private のワークフローが **public リポジトリを checkout** してスクリプトを取得」する構成だった。
これは **DB の全権認証情報を持ったまま public 側のコードを実行する**経路になる（SHA ピン留めは緩和にすぎない）。
→ **スクリプトを private 側に複製する**方式に変更し、依存自体を消した。
代償として「**public 側を更新したら private 側にもコピーする**」運用注意が発生するので、§5-3 と §9 に明記。

## 検証したこと

- `scripts/backup-db.sh` が「**成功したが中身が空**」で非ゼロ終了するかをスタブ CLI で実測
  → persons 0 行 / データダンプ切断のいずれも **exit 1 + 出力ファイル 0 個**。ログに平文パスワードは出ない
- cron `35 18 * * 0`（日曜 18:35 UTC）→ **月曜 03:35 JST**。400 週分計算して通年ブレないことを確認
  月初判定（UTC 1〜7 日）が **12 か月すべてちょうど 1 回**になることも確認
- YAML を Ruby(psych) でパース / 各 `run:` を `bash -n`（全 OK）
- gpg のラウンドトリップで sha256 が一致（MANIFEST の値と復号後を突き合わせられる）
