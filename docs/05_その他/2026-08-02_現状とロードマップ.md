#### 1-A. モデル対応（フェーズ 0 の結果に依存）

- [ ] **1-1. reasoning を切る**（0-3 で必要と判定された場合）

  **なぜ**: `TUTOR_MAX_TOKENS = 1200` の約半分が思考に消えると回答が途中で切れる。
  `SUMMARY_MAX_TOKENS = 400` では要約が 200 トークンしか出ず実質破綻する。
  可視出力が空になると `openaiCompatibleClient.ts:74` が `AiResponseFailedError` を投げ、生徒に `AI_RESPONSE_FAILED` が返る。

  **どこを直すか**: `src/features/ai-answer/lib/llm/openaiCompatibleClient.ts`。
  現在送っているのは `model` / `messages` / `max_tokens` / `temperature` の 4 つだけ。
  reasoning を無効化するパラメータを追加する（OpenAI 直と OpenRouter でパラメータ名が違う可能性があるので、
  0-1 の実測で通った形を使う）。

  **注意**: `LlmGenerateParams`（`types.ts`）に項目を足すなら、`summarizeThread` と `evaluate` の呼び出しにも影響する。
  `evaluate` は到達不能（監査確認済み）だが型は通す必要がある。

  **完了条件**: 実キーで叩いて `reasoning_tokens` が 0 か十分小さくなり、可視回答が 500 トークン前後出る。
  ユニットテストにパラメータ送信の検証を追加した。

- [ ] **1-2. `MODEL_PRICING` に luna / terra を追記**

  **なぜ**: 未登録だとコストが `$0.00` のまま積み上がる。**上限を設けるのに管理画面が 0 円に見えるのは最悪の食い違い。**
  しかも記録済みログは遡って再計算されない。

  **コード**: 決定事項 §3-4 にそのまま貼れる形で書いてある。0-1 で確定した正式 ID をキーにする。

  **完了条件**: `/admin/usage` の「単価が未登録のモデル」警告が出ない。`calculateCost.test.ts` にケース追加。

- [ ] **1-3.（条件付き）画像の `detail` 指定 / 送信前リサイズ**

  0-2 で「1 枚 10,000 トークン超」だった場合のみ。

  | 選択肢 | 内容 | トレードオフ |
  |---|---|---|
  | `detail: "low"` を指定 | 512×512 に縮小して処理 | 安い・速い。**数式や手書きの細部が読めなくなる可能性** |
  | 送信前リサイズ | `processAttachments` で長辺 1,024 程度に縮小 | 精度とコストの中間。実装量は増える |
  | 何もしない | `original` のまま | 精度は最高。terra の $2/1M で課金 |

  **判断基準**: 塾の主用途は「数学の問題の写真」なので、**精度を落とすと機能価値が下がる**。
  月額が想定（$1.84）の 3 倍を超えないなら `original` のまま進めるのが妥当。

  完了条件: `✓ Verified` が出て、変更後の再インストールで警告バナーが消えた。

- [ ] **3-3. 管理ユーザー・生徒・チャンネル紐付けを登録する**

## 5. 塾に確認・依頼すること

### 5-1. Slack アプリのインストール権限（3-1 で判定してから）

`Request to Install` と表示された場合のみ。オーナー権限を持つ人に依頼する。

> Slack 左上のワークスペース名 → ツールと設定 → **アプリを管理する** → 右上の **設定**
> → 「アプリを管理できるユーザー」を **「ワークスペースのオーナーと選択したメンバー」** に変更
> → ドロップダウンから対象メンバーを追加して保存

これは「アプリ導入を承認する」権限のみで、メンバー管理・チャンネル管理は含まない。
⚠️ **スコープ変更のたびに再インストールが必要**なので、承認フローが挟まると作業が都度止まる。

### 5-2. ⚠️ 非公開チャンネルへの開発者の参加方針

非公開運用なので、開発者がチャンネルに入ると**生徒の学習相談・氏名を閲覧できる**。個人情報の取扱いの問題。

| 選択肢 | 内容 |
|---|---|
| (a) 一時参加 → 疎通確認後に退出 | 参加する旨と期間を書面で合意し、退出を 4-3 に含める |
| **(b) 開発者は入らず、`/invite` とチャンネル ID 取得だけ塾側にやってもらう** | 画面共有で誘導すれば 1 生徒 2 分程度。テストは**専用の生徒 + チャンネル**を作り、そこだけ開発者が入る |

**(b) + テスト専用チャンネルのみ参加**が権限も最小で事故も起きにくい。

### 5-3. データの保存場所に関する要件

**「データは国内限定」という要件があるか。** OpenAI は米国なので、この要件が出た時点で構成の前提が変わる。
契約前に確認すること。

### 5-4. 認識を合わせておくこと（機能の期待値ズレ防止）

| 項目 | 伝える内容 |
|---|---|
| 月次レポートは**手動運用** | AI 自動生成と保護者メール通知は未実装。スタッフが手書きで作成・承認する |

## 7. 検証スクリプトの仕様（scratchpad が消えた場合の再作成用）

`check_llm.py` — Python 単体 / 外部依存なし（`urllib` + `zlib` + `struct` + `getpass`）。

| # | チェック | 内容 |
|---|---|---|
| 1 | 認証 | `GET /models`。401 なら即中断 |
| 2 | モデル実在確認 | `/models` の `data[].id` を `gpt-5` / `luna|terra|sol` / `gpt-4o` / `embedding` で分類表示。`LLM_MODEL_DEFAULT` / `COMPLEX` が一覧にあるか判定 |
| 3 | Chat | `max_tokens: 1200` で叩き、応答本文 / `usage` / `finish_reason` / `reasoning_tokens` を表示。空応答と reasoning 過剰消費を検出。**400 かつ `max_tokens` 絡みなら `max_completion_tokens` で自動再試行** |
| 4 | Vision | **64×64 の赤い PNG を実行時に生成**（zlib 圧縮 + CRC 計算）して data URL で送り、「赤」と答えるか判定。`prompt_tokens` で画像 1 枚のトークン数を表示 |
| 5 | Embedding | `encoding_format: 'float'` で叩き、次元が 1536 か / 先頭が全ゼロでないかを検証 |

環境変数で上書きできる項目: `LLM_BASE_URL` / `LLM_MODEL_DEFAULT` / `LLM_MODEL_COMPLEX` / `EMBEDDING_BASE_URL` / `EMBEDDING_MODEL` / `LLM_API_KEY`。

⚠️ **ハードコードした base64 画像は使わない。** 壊れた PNG は `image_parse_error` で偽陰性になる（一度踏んだ）。
