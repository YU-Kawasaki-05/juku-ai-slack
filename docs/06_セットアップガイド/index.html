じゅくAI 新規セットアップガイド

塾ごとに Slack + Supabase + Vercel の環境を新しく用意して、じゅくAI を稼働させるまでの手順書です。 上から順に進めれば、生徒が Slack で質問して AI が答えるところまで到達します。

このガイドの読み方

  • <あなたのドメイン> のような <角括弧> は、あなたの環境の実値に置き換える箇所です。
  • 各ステップの先頭に「所要時間」「このステップで手に入るもの（控えるべき値）」があります。控えるべき値は必ずメモに残してください（後のステップで使います）。
  • チェックボックスはブラウザに保存されます（同じブラウザで開き直せば状態が残ります）。

1. 全体像

          生徒（Slack）
              │  @じゅくAI  この問題わからない
              ▼
   ┌──────────────────────────────┐
   │  Slack Events API             │  ※署名付きで POST
   └───────────────┬──────────────┘
                   │ POST https://<あなたのドメイン>/api/slack/events
                   ▼
   ┌──────────────────────────────────────────────────┐
   │  Vercel ── Next.js 15 (App Router)                │
   │   ① 署名検証 → 重複排除 → 反応するか判定           │
   │   ② jobs テーブルに登録 → 3 秒以内に 200 を返す     │
   │   ③ after() で本処理（maxDuration = 300 秒）       │
   │        🤔 付与 → RAG 検索 → LLM 生成               │
   │        → Slack に投稿 → 🤔 解除                    │
   │   ④ /admin 管理画面（スタッフ・管理者のみ）         │
   └───────┬───────────────────────────┬──────────────┘
           │                           │
           ▼                           ▼
   ┌───────────────────────┐   ┌──────────────────────────┐
   │  Supabase             │   │  LLM / Embedding          │
   │   PostgreSQL + RLS    │   │   OpenAI 互換 API          │
   │   pgvector (1536 次元) │   │   /chat/completions       │
   │   Auth（招待制）       │   │   /embeddings             │
   │   Storage: attachments│   └──────────────────────────┘
   └───────────────────────┘

ポイントは 3 つ。(a) Slack への ACK は 3 秒以内に返し、重い AI 処理は after() に逃がす。 (b) 「誰の質問か」は Slack のチャンネル ID から決まる（生徒が名乗る必要はない）。 (c) Cron は使わない。滞留ジョブの回収は管理画面を開いたときに走る。

3. ステップ一覧

  1. STEP 1事前準備 — 決めること約 30 分 LLM / Embedding プロバイダの選定、生徒チャンネルを公開にするか非公開にするか、プラン、月額コストの見積り
  2. STEP 2Supabase プロジェクト作成約 15 分 プロジェクト作成、API キー 3 種の取得、サインアップ無効化（必須）、URL 設定
  3. STEP 3DB マイグレーション適用約 15 分 32 本の migration を supabase db push、テーブル・バケット・kill_switches の確認
  4. STEP 4Slack アプリ作成約 20 分 manifest からアプリ作成、必要スコープ 5 種、Bot Token / Signing Secret / Bot User ID の取得
  5. STEP 5Vercel デプロイ約 20 分 リポジトリのインポート、環境変数の設定（通常 13〜15 個）、デプロイ、/login の表示確認
  6. STEP 6Slack イベント購読の設定約 10 分 Request URL の登録と Verified 確認、bot events の追加、再インストール
  7. STEP 7管理ユーザーと生徒の登録約 30 分 Auth ユーザー作成 + ロール付与 SQL（自分は admin）、生徒登録 → AI プロフィール → チャンネル作成 → /invite → 紐付け → レポート
  8. STEP 8本番疎通確認約 20 分 実際の Slack で質問 → 🤔 → 回答、スレッド追撃、画像、コスト記録、エラー/ジョブの確認
  9. STEP 9運用ガイド（引き渡し前に読む）約 15 分 緊急停止、レート制限、ジョブ管理、エラー対応フロー、退塾処理、月次コスト確認、バックアップ
  10. 別冊トラブルシューティング随時 症状 → 原因 → 対処の早見表。詰まったらここを先に見る
