じゅくAI スタッフ操作マニュアル

じゅくAI は、生徒が Slack で質問すると AI が答えてくれるしくみです。 ふつうの AI チャットと違うのは、その生徒のことを踏まえて答えるところです。 そのために必要な情報を用意するのが、スタッフのしごとです。

このマニュアルは、Slack と Web の画面が使えれば読めるように書いてあります。 プログラムの知識は必要ありません。紙に印刷しても使えます。

1. 全体像

   生徒（Slack）                          スタッフ（Web の管理画面）
       │                                        │
       │ 自分専用のチャンネルで質問する          │ 生徒を登録する
       │  「@じゅくAI この問題わからない」       │ AI 用プロフィールを書く
       │                                        │ 月次レポートを登録する
       ▼                                        │ 会話ログ・エラーを見る
   ┌──────────────────────┐                     │
   │  じゅくAI              │◀────────────────┘
   │                       │
   │  この生徒のことを      │   ・学年
   │  ふまえて答える        │   ・AI 用プロフィール（スタッフが書いた学習メモ）
   │                       │   ・承認済みの月次レポート
   └──────────┬───────────┘   ・同じスレッドのこれまでのやり取り
              │
              ▼
   生徒のチャンネルに回答が届く

スタッフが操作するのは Web の管理画面だけです。 生徒の Slack チャンネルにスタッフが書き込む必要はありません （チャンネルの中でスタッフが雑談しても、じゅくAI は反応しません）。

2. まず何を読むか

あなたの状況読む順番
はじめて担当になった第 1 章 → 第 2 章。ここまでで日々の仕事は回ります
新しい生徒を使えるようにしたい第 3 章（全体の流れ → 5 ステップ）
AI の答えの質を上げたい第 3 章「AI 用プロフィールの書き方」＋ 第 4 章
月が変わった第 4 章
生徒から「使えない」と言われた第 2 章「Bot が反応しないと言われたとき」→ 第 5 章
保護者や講師に説明したい第 6 章 ＋ 第 7 章
塾の管理者（責任者）である第 7 章は必ず読んでください（緊急停止・個人情報）

  2. 第 2 章毎日の確認 朝の 3 分チェック / エラーの見方 / 会話ログの見方 /「Bot が反応しない」と言われたときの手順

4. 最初に覚える 3 つ

① チャンネルを作ったら、Bot を招待する。 Slack のチャンネルで /invite @じゅくAI と打ちます。これを忘れると、じゅくAI は完全に無反応になります。 エラーの記録さえ残らないので、いちばん気づきにくいミスです。→ 第 3 章

② 紐付け（ひもづけ）を間違えない。 紐付けは「このチャンネルの質問は誰のものか」を決める設定です。間違えると 別の生徒の学習履歴とレポートを使って回答してしまいます。→ 第 3 章

③ AI 用プロフィールに生徒の氏名を書かない。 この欄に書いた文章はそのまま AI に送られます。氏名は答えの質を上げないので、書く必要がありません。 → 第 3 章

5. このマニュアルで使う言葉

言葉意味
管理画面スタッフが使う Web の画面。ログインが必要。生徒はログインできません
Bot（ボット）Slack の中にいる「じゅくAI」のこと。人ではなくアプリです
チャンネルSlack の会話の部屋。生徒 1 人につき 1 つ作ります
スレッドSlack で 1 つの発言にぶら下がる返信の列。話の続きはここで続けます
紐付け（ひもづけ）「このチャンネルの質問は誰のものか」を決める設定
AI 用プロフィールスタッフが書く生徒の学習メモ。AI が毎回の回答で参照します
月次レポート生徒ごと・月ごとの学習記録。承認すると AI が参照できるようになります
緊急停止全生徒への AI 回答をすぐに止めるボタン。管理者のみ操作できます
スタッフ / 管理者管理画面にログインできる人の 2 種類。緊急停止だけは管理者専用です

このマニュアルは塾で日々使う操作を扱います。 最初の環境づくり（アプリを作って動かすまで）は開発者向けの セットアップガイド にあります。
