## ID の読み方（重要）

3 系統ある。**混ぜて読まないこと。**

| プレフィックス | 意味 | ID の出どころ |
|---|---|---|
| `AT-05` `AT-30` … | 受け入れテスト専用 spec（`e2e/acceptance/`） | **spec のテスト名に AT 番号が書かれている**。この文書はそれを転記しているだけ |
| `AT-B01` … | 基礎 E2E（`e2e/` 直下 + `e2e/usage-cost-warning.spec.ts`）で担保 | **本レポートで採番**。spec 側に番号は無いため、対応するテスト名を併記する |
| `AT-P01` … | 本番疎通送り（ローカルで再現不能） | **本レポートで採番**。`90_本番疎通チェックリスト.md` と 1:1 |

AT 番号には欠番がある（AT-01〜04, AT-07, AT-15〜29, AT-42, AT-45, AT-46）。
これは設計段階で確保した番号のうち spec に落ちなかったもので、**欠番のまま残す**。
番号を詰めると既存 spec のテスト名と食い違うため。
